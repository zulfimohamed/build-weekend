# departure-board

A split-flap airport departure board, the kind that clatters. It invents a
schedule of flights (some more plausible than others), drifts their remarks
over time the way a real board does — boarding, final call, departed, the
occasional cancellation — and lets you type any message to watch it clatter
into place letter by letter.

Turn the sound on for the full effect.

## Run it

Open `index.html` in a browser. That's the whole deployment story.
