# airline logos

Drop PNG files here named by ICAO callsign prefix — `MAS.png`, `UAE.png`,
`SIA.png`, `BAW.png`, and so on — and the app picks them up automatically,
replacing the brand-color word marks in the sidebar and timetable.

Square-ish images with transparency work best (they're shown on a white
tile at 44×44). No files here means the styled word marks are used —
which already carry each airline's brand colors.

Make sure you have the rights to use any logo files you add.
