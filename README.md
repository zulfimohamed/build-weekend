# build-weekend

Some weird things I build. Has limited use — and that's the point.

This is my playground for cool web projects. Anything goes: the most basic
experiments, silly one-page toys, half-finished ideas, things that exist purely
because they were fun to make. There are no rules here — no roadmap, no
"is this useful?" filter, no polish requirements. If it sounds fun to build on
a weekend, it belongs in this repo.

## What to expect

- **Small web projects** — HTML/CSS/JS experiments, tiny apps, visual toys,
  anything browser-flavored.
- **No limitations** — projects can be as basic or as strange as they want to be.
- **Built for fun, not production** — things here may be rough, unfinished, or
  gloriously pointless. Use at your own delight.

## Projects

Nothing here yet — this space will fill up as weekend builds land. Each project
will live in its own folder with a short note on what it is and how to run it.
